Технический стек

Frontend: React

React 19 + TypeScript используются для пользовательского интерфейса: трекер, цели, аналитика, тарифы, настройки, поддержка и админ-панель.

Дополнительно: Vite, Tailwind CSS, React Router, Axios, Zustand, React Query, Framer Motion.

Backend: Java / Spring Boot

Java 17 + Spring Boot 4 используются для REST API, бизнес-логики, авторизации, подписок, платежей, аналитики, поддержки и AI-сводок.

Дополнительно: Spring Security, JWT, Spring Data JPA, Spring Mail, Spring Scheduler, MapStruct, Lombok.

Database: PostgreSQL

PostgreSQL 16 хранит пользователей, трекеры, отметки, цели, подписки, платежи, обращения, рефералы, друзей и AI-сводки.

DB Migrations: Liquibase

Liquibase управляет изменениями структуры базы данных и версионирует миграции.

Runtime: Docker

Docker и docker-compose используются для production-развёртывания backend, frontend, PostgreSQL и дополнительных сервисов.

AI: Ollama / qwen2.5

Ollama с моделью qwen2.5 генерирует AI-сводки, инсайты и советы по данным пользователя.

Интеграции
