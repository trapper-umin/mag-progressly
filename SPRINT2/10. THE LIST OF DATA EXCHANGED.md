# Карта обмена данными

| Система | Входящие данные | Исходящие данные |
|---|---|---|
| **SMTP** | • **delivery_result.status**: результат отправки письма, например `success` / `error` | • **magic_link_email.from**: отправитель письма<br>• **magic_link_email.to**: email пользователя<br>• **magic_link_email.subject**: тема письма для входа<br>• **magic_link_email.html**: HTML-письмо с кнопкой входа<br>• **magic_link_email.link**: ссылка magic link для авторизации<br><br>• **notification_email.from**: отправитель уведомления<br>• **notification_email.to**: email пользователя<br>• **notification_email.subject**: тема уведомления<br>• **notification_email.html**: HTML-текст уведомления<br>• **notification_email.base_url**: ссылка на Progressly<br>• **notification_email.settings_url**: ссылка на настройки |
| **Telegram OAuth / OIDC** | • **token_exchange_response.id_token**: JWT-токен от Telegram<br>• **jwks_response.keys**: публичные ключи для проверки подписи JWT<br>• **decoded_user_info.telegram_id**: Telegram ID пользователя<br>• **decoded_user_info.name**: имя пользователя<br>• **decoded_user_info.username**: username в Telegram<br>• **decoded_user_info.photo_url**: ссылка на аватар | • **token_exchange_request.method**: `POST`<br>• **token_exchange_request.url**: `https://oauth.telegram.org/token`<br>• **token_exchange_request.headers.Authorization**: Basic-авторизация клиента<br>• **token_exchange_request.form.grant_type**: тип авторизационного flow<br>• **token_exchange_request.form.code**: код авторизации Telegram<br>• **token_exchange_request.form.redirect_uri**: callback Progressly<br>• **token_exchange_request.form.client_id**: ID Telegram OAuth-клиента<br>• **token_exchange_request.form.code_verifier**: PKCE verifier<br><br>• **jwks_request.method**: `GET`<br>• **jwks_request.url**: URL получения JWKS-ключей |
| **Telegram Bot API** | • **send_message_response.ok**: результат отправки сообщения<br>• **send_message_response.result.message_id**: ID отправленного сообщения<br>• **send_message_response.description**: описание ошибки, если есть | • **send_message_request.method**: `POST`<br>• **send_message_request.url**: endpoint Telegram Bot API<br>• **send_message_request.json.chat_id**: Telegram ID получателя<br>• **send_message_request.json.text**: текст напоминания |
| **YooKassa** | • **create_payment_response.id**: ID платежа в YooKassa<br>• **create_payment_response.status**: статус созданного платежа<br>• **create_payment_response.amount**: сумма и валюта платежа<br>• **create_payment_response.confirmation.confirmation_url**: ссылка на оплату<br>• **create_payment_response.metadata**: служебные данные Progressly<br><br>• **payment_status_response.status**: актуальный статус платежа<br>• **payment_status_response.payment_method.id**: сохранённый способ оплаты<br>• **payment_status_response.payment_method.saved**: признак сохранения метода оплаты<br>• **payment_status_response.cancellation_details.reason**: причина отмены, если есть<br><br>• **webhook.source_ip**: IP-адрес отправителя webhook<br>• **webhook.body.event**: событие оплаты, например `payment.succeeded`<br>• **webhook.body.object.id**: ID платежа<br><br>• **refund_response.id**: ID возврата<br>• **refund_response.status**: статус возврата<br>• **refund_response.payment_id**: ID исходного платежа<br>• **refund_response.amount**: сумма возврата | • **create_initial_payment.method**: `POST`<br>• **create_initial_payment.url**: endpoint создания платежа<br>• **create_initial_payment.headers.Authorization**: Basic-авторизация магазина<br>• **create_initial_payment.headers.Idempotence-Key**: ключ идемпотентности<br>• **create_initial_payment.json.amount**: сумма и валюта<br>• **create_initial_payment.json.confirmation.return_url**: URL возврата после оплаты<br>• **create_initial_payment.json.description**: описание подписки<br>• **create_initial_payment.json.merchant_customer_id**: ID пользователя<br>• **create_initial_payment.json.metadata**: user ID, период, тип платежа, billing attempt<br><br>• **create_recurring_payment.payment_method_id**: сохранённый метод оплаты<br>• **create_recurring_payment.metadata.billing_cycle_key**: ключ периода автопродления<br><br>• **get_payment_status.method**: `GET`<br>• **get_payment_status.url**: URL проверки статуса платежа<br><br>• **create_refund.method**: `POST`<br>• **create_refund.url**: endpoint создания возврата<br>• **create_refund.json.payment_id**: ID платежа<br>• **create_refund.json.amount**: сумма возврата |
| **Ollama** | • **generate_response_raw.response**: сырой JSON-ответ модели строкой<br>• **generate_response_parsed.summary**: краткая AI-сводка<br>• **generate_response_parsed.insights**: список инсайтов<br>• **generate_response_parsed.advice**: список советов<br>• **generate_response_parsed.confidence**: уровень уверенности модели | • **generate_request.method**: `POST`<br>• **generate_request.url**: endpoint локальной модели Ollama<br>• **generate_request.headers.Content-Type**: `application/json`<br>• **generate_request.json.model**: модель, например `qwen2.5:3b`<br>• **generate_request.json.prompt**: промпт с пользовательскими данными<br>• **generate_request.json.stream**: режим потоковой генерации<br>• **generate_request.json.format**: формат ответа, например `json` |
