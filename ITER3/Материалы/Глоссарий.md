# Глоссарий проекта Progressly

Термины предметной области в том виде, в каком они используются в спецификациях,
диаграммах последовательности и проектной диаграмме классов. Имя класса в модели
совпадает с термином.

| Термин | Класс модели | Значение |
|---|---|---|
| Пользователь | `Пользователь` | Человек, который ведёт самоотслеживание. Идентифицируется по email или телеграм-аккаунту |
| Платящий пользователь | — (актор) | Пользователь с активной подпиской PRO; наследует все действия пользователя |
| Сессия | `Сессия` | Подтверждённый вход: токен с ограниченным сроком жизни |
| Подписка | `Подписка` | Право пользоваться платными возможностями в течение периода. Тарифы: FREE, FREE_PRO, PRO |
| Платёж | `Платёж` | Операция оплаты подписки через YooKassa; имеет статус СОЗДАН / ОПЛАЧЕН / ОТКЛОНЁН |
| Трекер | `Трекер` | Таблица самоотслеживания, которую пользователь собирает сам: набор полей и периодичность заполнения |
| Поле трекера | `ПолеТрекера` | Один показатель в трекере. Шесть типов: число, шкала, флаг, текст, выбор, время |
| Периодичность | `Периодичность` | Как часто трекер подлежит заполнению: ежедневно, еженедельно, ежемесячно |
| Запись | `Запись` | Заполнение трекера за конкретную дату. Статус: пусто, частично, заполнено |
| Значение поля | `ЗначениеПоля` | Значение одного поля внутри записи |
| Стрик | `Стрик` | Непрерывная последовательность заполненных периодов. Хранит текущую длину и рекорд |
| Восстановление стрика | — (сценарий) | Платная возможность вернуть прерванный стрик |
| Цель | `Цель` | Целевое значение по конкретному полю на период; имеет статус достижения |
| Группа целей | `ГруппаЦелей` | Набор связанных целей, объединённых пользователем |
| Прогресс | — (представление) | Сводное состояние: заполненность периода, стрик, достижение целей |
| Аналитика | — (представление) | Агрегаты по записям за день, неделю, месяц; детализация по отдельному полю |
| AI-сводка | `AI-сводка` | Текст, инсайты и советы, сформированные моделью по записям и целям за период |
| Инсайт | — (часть AI-сводки) | Наблюдение о закономерности в данных пользователя |
| Совет | — (часть AI-сводки) | Рекомендация по изменению поведения на следующий период |
| Уведомление | `Уведомление` | Сообщение пользователю: напоминание о заполнении, сообщение о готовой сводке |
| Обращение | — (вне итерации) | Сообщение пользователя в поддержку |

## Внешние системы

| Термин | Класс-адаптер | Назначение |
|---|---|---|
| Telegram Bot API | `КлиентTelegram` | Вход через Telegram-виджет и доставка уведомлений |
| SMTP-сервер | `КлиентEmail` | Отправка писем: magic link и уведомления |
| YooKassa | `КлиентYooKassa` | Приём платежей за подписку |
| qwen2.5 | `КлиентQwen` | Локальная языковая модель, формирующая AI-сводки |
| Планировщик | — (вне итерации) | Запуск автопродления подписки и регулярных рассылок |

## Соглашения об именовании

- Классы предметной области и управления названы по-русски существительными: `Трекер`, `МенеджерТрекера`.
- Граничные классы начинаются со слова «Страница» или «Клиент»: `СтраницаТрекера`, `КлиентQwen`.
- Операции названы глаголами в инфинитиве: `проверитьПериодичность`, `сохранитьЗапись`.
- Имя сообщения на диаграмме последовательности совпадает с именем операции класса-получателя.
